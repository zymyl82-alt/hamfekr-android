هم‌فکر | پروژهٔ آزمایشی اندروید

طراح: فرنگیس نوری، مشاور دبیرستان‌های هرسین استان کرمانشاه
شعار: هم‌افزایی اندیشه انسان و هوش مصنوعی در یادگیری

این مخزن شامل سورس اپلیکیشن اندروید و نسخهٔ عمومی آزمایشی محتوای تعاملی انگلیسی هفتم است.

ساخت APK: از زبانهٔ Actions گردش‌کار Build Hamfekr APK را اجرا کنید؛ با هر push به شاخهٔ main نیز ساخت خودکار اجرا می‌شود. خروجی در بخش Artifacts همان اجرا با نام Hamfekr-debug-apk قرار می‌گیرد.

PDF کتاب درسی و فایل‌های صوتی به دلیل رعایت حقوق نشر در این مخزن عمومی قرار نگرفته‌اند.

نیازمندی ساخت محلی: Java 17، Android SDK Platform 35 و Gradle 8.9.
